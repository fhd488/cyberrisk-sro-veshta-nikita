# CyberRisk Lab

Учебный проект по дисциплине «Киберриск и киберразведка».

## Цель

Создать веб-сайт и развернуть его с использованием
Docker, GitHub и AWS EC2.

## Технологии

- Python
- Flask
- Docker
- GitHub
- AWS EC2

## Локальный запуск

Сборка образа:

    docker build -t cyberrisk-site .

Запуск контейнера:

    docker run -d --name cyberrisk-web -p 5000:5000 cyberrisk-site

Сайт: http://localhost:5000

## Исследование киберрисков

В рамках проекта изучаются настройки доступа,
сетевые службы, безопасность зависимостей и HTTPS.

## Киберразведка

Исследование проводится только для собственного
учебного ресурса и разрешённых объектов.
